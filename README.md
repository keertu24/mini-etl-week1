
# Mini-ETL Project: CSV → Python → PostgreSQL

## Overview
This project demonstrates a simple ETL pipeline:
1. **Extract**: Ingest CSV file.
2. **Transform**: Clean and preprocess with Pandas.
3. **Load**: Insert into PostgreSQL table.

## Tech Stack
- Python (Pandas, SQLAlchemy, psycopg2)
- PostgreSQL
- Git/GitHub for version control
